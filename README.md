# web-ootd-blog

실행 방법 : 링크를 타고 들어가기.

기능 :
New Post : 데일리룩 게시글 확인
Catalog : 스타일별 이미지 분류 및 조회
Photos : 사진을 갤러리 형태로 제공
반응형 디자인으로 화면 크기에 따른 레이아웃 제공

핵심 코드 : 사용자가 카테고리 버튼을 클릭했을 때 해당 카테고리를 선택하도록 만드는 코드
js/app.js

tabs.forEach((tab) => {
    tab.addEventListener('click', () => selectTab(tab));
});


코드를 사용한 이유 : 
카테고리에 클릭 이벤트를 적용하여 사용자가 원하는 스타일의 이미지를 확인할 수 있도록 구현했습니다.
반복문을 활용해 카테고리를 효율적으로 관리하고자 했습니다.
